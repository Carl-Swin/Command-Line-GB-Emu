# Command-Line-GB-Emu
This application aims to bring a Gameboy emulator to desktop with the graphics being fully rendered on the Windows command line. This is derived from my Command-Line-Tetris repository and will use a similar technique to rendering.

For SDL headers, go to https://libsdl.org/release/ and find the latest release. Make sure to place the headers in the system include directory. Put SDL3.dll somewhere it can easily be compiled with and used by the executable.
